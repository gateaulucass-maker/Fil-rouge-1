Classement des stacks

Les quatre combinaisons du benchmark, notées critère par critère et classées sur 100. Chaque note dit d’où elle vient. La stack A, en code avec React, Next.js, Supabase et n8n, reste devant, mais rien n’est encore testé.

Pourquoi Claude Code n’est plus dans le nom. Un outil qui écrit du code n’est pas une stack : la stack, c’est ce qui fait tourner le produit. Le benchmark du 16 octobre et le compte rendu de Camille disaient « Claude Code + … ». À écrire partout de la même façon désormais : React + Next.js + Supabase + n8n, construit avec Claude Code.

L’échelle

Comment chaque note est donnée

Une note sans échelle ne vaut rien. Voici ce que valent 5, 3 et 1 pour chaque critère. Les notes 4 et 2 sont entre deux. Le score total est la somme des notes multipliées par leur poids, ramenée sur 100.

Le test commun joué sur A et D d’abord : le toucher, de l’envoi à la notification de l’aidant, avec un cas invalide et un doublon. Puis le site vitrine, l’écran du cadre, l’alerte.
