# Résumé du projet : PFR Générations Connectées

**Contexte.** Projet fil rouge Ynov B2 Product Builder No-Code 2026-2027, thème silver economy : rassurer les familles sur leurs proches âgés. Équipe de trois : Clément, Lucas, Camille.

**Problème.** Les enfants aidants s'inquiètent pour leur parent âgé, mais le parent refuse la complexité : pas d'appli, pas de compte, pas d'appel vidéo.

**Solution.** Un cadre photo mural chez le parent et une application pour l'enfant aidant. Le parent n'a rien à installer ni à faire.

**Ce que fait le produit.**
- L'aidant envoie trois types de contenus : photo, vidéo, message. Le sens est unique, de l'aidant vers le parent.
- Quand le parent touche le cadre, l'enfant reçoit « votre parent est là ». Un nouveau toucher remet le compteur à zéro.
- Alerte de secours uniquement si le parent l'a acceptée à l'installation : après plus de 48 h sans toucher, les aidants sont prévenus en premier.
- Écartés volontairement : appel audio ou vidéo, messages vocaux, appli parent, « vu ».

**Direction artistique.** Style chaleureux et lisible : Aube, Crème, Encre, Soleil, Pêche, Lilas. Typos Lexend (titres) et Atkinson Hyperlegible (texte). Composants sobres, boutons pilule, un seul bouton principal par écran.

**État d'avancement.**
- Fait : veille, verbatims et synthèse des entretiens famille, personas, DA, prototype interactif cadre + appli (v2, puis v3 enrichie).
- En cours : audit et correction de la v3 (bugs, boutons manquants, parcours complet, barre noire en haut du téléphone).
- À trancher : qui appelle les secours.

**Règles d'équipe.** Dépôt public : aucun secret, aucun nom ni coordonnée de tiers. Chacun travaille dans son dossier `interne/<prénom>/`, les versions validées vont dans `rendus/`.
